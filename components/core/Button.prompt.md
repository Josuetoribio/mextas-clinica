Botón de acción; usa `primary` (verde profundo) para la acción principal de cada vista y `secondary` para la alterna.

```jsx
<Button variant="primary" size="lg" icon={<CalendarIcon/>}>Agendar cita</Button>
<Button variant="secondary">Conocer especialidades</Button>
```

Variantes: `primary` | `secondary` | `ghost` | `gold` (solo texto/borde dorado, nunca relleno) | `inverse` (sobre banda verde). Tamaños `sm|md|lg`. Un solo primario por sección.
